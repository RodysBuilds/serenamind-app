# SerenaMind V15 Local publiceren
1. Pak deze ZIP uit.
2. Open RodysBuilds/serenamind-app op GitHub.
3. Upload alle losse bestanden naar de root.
4. Controleer dat local-auth.js aanwezig is.
5. Vervang de bestaande bestanden en commit: SerenaMind V15 eenvoudige lokale login.
6. Wacht tot Actions groen is.
7. Open https://rodysbuilds.github.io/serenamind-app/?v=15
8. Controleer dat v15-local bovenaan staat.
9. Maak een nieuw lokaal testaccount. Er is geen e-mail, cloud of herstelcode nodig.
