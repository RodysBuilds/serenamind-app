# SerenaMind V7 op GitHub bijwerken

1. Pak deze ZIP uit.
2. Open de GitHub repository en kies Add file > Upload files.
3. Upload ALLE bestanden uit deze map naar de root.
4. Kies Replace wanneer GitHub dat vraagt en commit met `SerenaMind V7 login en update fix`.
5. Controleer Actions tot Pages build and deployment groen is.
6. Open de Pages-link met `?v=7` erachter.
7. Een bestaande gedeelde link blijft hetzelfde en toont na verversen automatisch V7.

V7 bewaart de actieve gebruiker in lokale permanente browseropslag. Alleen bewust Uitloggen verwijdert de actieve sessie. De service worker haalt nieuwe bestanden eerst van het netwerk en activeert updates direct.
